
You will find the four files input needed for running CANVAS sucessfully. The file contains data collected in MPI Marburg and processed with MS-DIAL 5.5 and Sirius 6.1. 
- Areas -> Integrated areas from raw files aligned with MS-DIAL
- Structure -> Top1 structure annotation from Sirius CSI:Finger ID
- Canopus -> Ontology file containing ClassyFire and NPC classification for the best structure
- Metatada -> Manually curated metadata describing the experiment variables
